# SN²H team photographs

Initials are displayed until real photographs are supplied. Suggested future filenames:

- `sagar.jpg` — Sagar S Gourimath
- `nandish.jpg` — Nandeswara M (Nandish)
- `nagaraj.jpg` — Nagaraja C Y
- `hemanth.jpg` — Hemanth Kumar (Heymanth)

Set the corresponding `photo` field in `public/team.js`, for example `/assets/images/team/sagar.jpg`. A failed image falls back to the initials avatar. There is no upload service; adding a supplied file and changing its configuration path is all that is needed.
